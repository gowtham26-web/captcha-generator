# captcha-generator
📄 Description: Simple CAPTCHA Generator
This project is a basic CAPTCHA generator built using HTML, CSS, and JavaScript. It displays a randomly generated 6-character alphanumeric code that users must correctly type into an input field to verify they are human.

Key features:

Generates a new CAPTCHA code on page load or by clicking "Refresh CAPTCHA".

Compares user input to the generated CAPTCHA code.

Provides feedback on whether the input is correct or not.

Designed with basic styling for readability and usability.

This is a beginner-friendly example and can be enhanced with visual noise, distortion, or server-side validation for added security.
